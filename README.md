### nestly · 가구 배치 사전 시각화

> 이사 전에 **"내 가구가 새 집에 들어갈까?"** 를 미리 확인하는 서비스 · 기획 · 프론트 · 백엔드 **1인 개발** · 출시 준비 중

가구 간 겹침과 여유, 문 여닫이 공간, 무타공 가구의 벽 접촉을 좌표와 치수로 계산해 초록·노랑·빨강으로 판정합니다. AI 자동배치는 만들었다가 접고, 사용자가 직접 배치하면 코드가 판정하는 구조로 다시 짰습니다. 판정은 순수함수로 격리했고, 안 들어가는 가구를 초록으로 통과시키는 「거짓 초록」을 잡기 위해 고치기 전에 반드시 실패하는 반례 테스트를 완료 기준으로 둡니다.

`React 19` · `TypeScript` · `Spring Boot 3.5` · `Java 21` · `PostgreSQL`

→ [**nestly 소개 · 설계와 화면 시안**](https://github.com/nestly-apps) (코드는 출시 준비로 비공개)
